# Changelog

All notable changes to LEZ Wallet UI are documented in this file.

## [1.1.0] - Alpha

### Changed

- Update the wallet UI package for the current release.

## [1.0.4] - Alpha

### Fixed

- Resolve public-account initialization status before historical wallet synchronization completes.
- Require explicit confirmation before submitting public-account initialization transactions.
- Keep the confirmation dialog fully visible on the wallet screen.

## [1.0.3] - Alpha

### Added

- Source-owned prerelease packaging for the portable Wallet UI module.
- Public account registration and synchronization support.

### Changed

- Align the runtime plugin version with the package metadata.
- Use the matching LEZ Core release as the wallet backend dependency.
